Poisson Distribution

From real-world events → rate λ → Poisson model → probability

Why do we need the Poisson Distribution?

Suppose events occur randomly over time or space.
How many events should we expect in a fixed interval?

Imagine counting customers arriving at a service desk during a 10-minute interval. Instead of asking exactly when each customer arrives, we ask:

  • What is the probability of getting exactly 0, 1, 2, … events?
  • What happens when the average event rate changes?
  • What happens when we repeat the counting experiment many times?

The Poisson Distribution is useful for counting events occurring in a fixed interval when events occur independently at an approximately constant average rate.

From real-world events to a distribution

1. Choose an interval
Example: 10 minutes
2. Define the event
Example: customer arrival
3. Specify the rate
Average number of events = λ
4. Count events
X = number of events
If the average number of events in the chosen interval is λ, then the count X follows a Poisson Distribution:
X ~ Poisson(λ)

🎯 A concrete example

Customer arrivals: Suppose a help desk receives an average of 4 customers every 10 minutes.

Let “customer arrival” be the event. Then:

λ = 4,   X = number of customers arriving in 10 minutes

We can ask: What is P(X = 2)? What is the expected number of arrivals?

Similar ideas appear in phone calls, website requests, machine failures, radioactive decay counts, defects, traffic arrivals, and other event-counting problems.

📘 The Poisson Model

A random variable X is modeled as Poisson when we count events in a fixed interval and the events are reasonably described by:

  1. A fixed time, length, area, or volume interval is selected.
  2. Events occur independently of one another.
  3. The average event rate is approximately constant over the interval.
  4. The probability of multiple events in an extremely small interval is negligible.
  5. X counts the number of events in the chosen interval.
P(X=k) = e−λ λk / k!,   k=0,1,2,…
Mean E(X)λ
Variance Var(X)λ
SD√λ

🔎 Why does the formula look like this?

The Poisson PMF has two important ingredients:

e−λ × λk / k!

λ controls the average number of events, while k is the number of events whose probability we want to calculate. The factorial k! accounts for the ordering of the events in the count.

Key teaching point: Unlike the Binomial Distribution, Poisson does not require a fixed number of trials n. We specify an interval and an average event rate λ.

🧪 Virtual Experiment

Choose the average number of events λ and repeat the counting experiment many times. Each repetition records only the number of events.

Run the experiment to compare the experimental frequencies with the theoretical Poisson probabilities.
What should students notice?
With only a few repetitions, the experimental histogram is noisy. As the number of repetitions increases, it approaches the theoretical Poisson PMF. This illustrates the law of large numbers.
