SINGULAR PERTURBATIONS — f(z) = zⁿ + c + ε/zⁿ (Plates 30–31)

Start from a familiar polynomial Julia set — the basilica, the Douady rabbit, or the "cubic rat" — then add a pole term $\varepsilon/z^n$ so tiny it looks like it should do nothing. It doesn't do nothing: even $\varepsilon=0.0001$ replaces the clean polynomial boundary with an infinitely lacy new structure. Slide $\varepsilon$ from $0$ upward and watch the lace grow out of the original shape.
