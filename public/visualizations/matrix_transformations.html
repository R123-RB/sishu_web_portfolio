How the matrix encodes each transformation

Scaling: [[sx, 0], [0, sy]] — top-left scales x, bottom-right scales y. Values > 1 stretch, < 1 compress, negative values flip.

Rotation by θ: [[cosθ, −sinθ], [sinθ, cosθ]] — rotates every point around the origin by angle θ.

Shear: [[1, k], [0, 1]] — slides each point horizontally by k times its y-coordinate. Keeps area unchanged.

Composition: this applet computes R(θ) · S · x, so the displayed matrix is their product — one matrix capturing all three operations at once.
