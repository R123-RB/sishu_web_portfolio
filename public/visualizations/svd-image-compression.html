How it works
SVD decomposes any matrix A into A = U · Σ · Vᵀ. We can rewrite this as a sum of rank-1 matrices:

  A = σ₁(u₁⊗v₁ᵀ) + σ₂(u₂⊗v₂ᵀ) + ··· + σᵣ(uᵣ⊗vᵣᵀ)

Each term is an outer product of one column of U with one row of Vᵀ, scaled by a singular value σᵢ. Since σ₁ ≥ σ₂ ≥ ··· ≥ 0, the first terms carry the most information.

Image compression: keep only the first k terms. You need to store k·(m + n + 1) numbers instead of m·n. Drag the rank slider to see how few terms it takes to recognise the image!
