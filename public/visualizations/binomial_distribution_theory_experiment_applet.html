Binomial Distribution

From a real-world experiment → Bernoulli trials → Binomial model → probability

Why do we need the Binomial Distribution?

Suppose I repeat the same yes/no experiment many times.
How many successes should I expect?

Imagine tossing a coin 10 times. Instead of asking what happens on each individual toss, we ask:

  • What is the probability of getting exactly 0, 1, 2, …, 10 heads?
  • What happens if the probability of a head is not 0.5?
  • What happens when we repeat the experiment many times?

The Binomial Distribution answers these questions when the experiment consists of a fixed number of independent trials, each having the same probability of success.

From experiment to distribution

1. Define one trial
Example: toss a coin once
2. Define success
Head = success
Tail = failure
3. Repeat n times
Keep p the same and make trials independent
4. Count successes
X = number of successes
So if each trial has success probability p, and we perform n independent trials, then the count of successes X follows a Binomial Distribution:
X ~ Binomial(n,p)

🎯 A concrete example

Quality control: Suppose 10 components are tested. Historical data says each component has a 10% probability of being defective.

Let “defective” = success. Then:

n = 10,   p = 0.10,   X = number of defective components

Now we can ask: What is P(X = 2)? What is the expected number of defective components?

The same mathematical structure appears in coin tossing, pass/fail tests, customer conversion, reliability testing, medical screening, and many other settings.

📘 The Binomial Model

A random variable X is binomial when:

  1. There are a fixed number n of trials.
  2. Each trial has exactly two outcomes: success or failure.
  3. The probability of success is the same p on every trial.
  4. The trials are independent.
  5. X counts the number of successes.
P(X=k) = C(n,k) pk(1-p)n-k,   k=0,1,…,n

Here C(n,k) counts how many different arrangements contain exactly k successes.

Mean E(X)np
Variance Var(X)np(1-p)
MGF M(t)(q+peᵗ)n

🔎 Why does the formula look like this?

For one particular sequence containing k successes and n−k failures, independence gives

pk(1−p)n−k.

But the k successes can occur in many different positions. The number of such arrangements is

C(n,k) = n! / [k!(n−k)!].

Multiplying these two ingredients gives the binomial PMF.

🧪 Virtual Experiment

Choose a trial probability and repeat the whole experiment many times. Each repetition records only the number of successes.

Run the experiment to compare the experimental frequencies with the theoretical binomial probabilities.
What should students notice?
With only a few repetitions, the experimental histogram can look noisy. As the number of repetitions increases, it approaches the theoretical Binomial PMF. This is a visual demonstration of the idea behind the law of large numbers.
